けいたろう秘書（slack-secretary）を動かすまでの7ステップ

2026-08-31 作成／2026-09-01 更新（public/private脳分離でステップ5・6を追加） ／ 上から順にやれば動きます ／ 所要目安 25〜35分

1GitHub Billingの解消（最優先）

「GitHub Billing」＝GitHub Actionsの利用料金の設定のことです。今、リポジトリの自動実行（CI・5分ごとの秘書起動）が次のエラーで起動すらできない状態です：

The job was not started because recent account payments have failed or your spending limit needs to be increased.
（最近の支払いが失敗しているか、使用上限の引き上げが必要です）

原因は次のどちらかです。まず①を開いて確認してください。

📍 確認場所: https://github.com/settings/billing（groundcobra009でログインした状態で）

原因A: 無料枠の使い切り（可能性大）

privateリポジトリのGitHub ActionsはFreeプランで月2,000分まで無料。groundcobra009には毎日動くActions（バズ投稿ランナー等）が複数あるため、月末の今日（8/31）に使い切っている可能性が高いです。Billing画面の「Actions」の使用量バーが100%なら確定。

  • 対処①（お金をかけない）: 明日9/1の請求サイクルリセットを待つ。ただし毎月月末に同じ症状が再発します
  • 対処②（推奨）: Spending limit を $0 → 数ドル（例: $5〜10）に引き上げる。超過分は $0.008/分。5分cronの秘書は月あたり概ね数百〜千円台の見込み

原因B: 支払い方法の決済失敗

カードの期限切れ等。Payment information でカード情報を更新してください。

✅ 確認方法: 解消後、Actionsタブ で「CI」workflowの「Re-run all jobs」を押して緑になればOK。

2Claudeのセットアップトークン発行（ターミナル）

  1. ターミナル.appを開いて次を実行: 
    claude setup-token
  2. ブラウザが開くので、Claude Maxのアカウントでログインして承認
  3. ターミナルに sk-ant-oat… で始まる長いトークンが表示される。これをコピー（この画面にしか表示されないので、その場でステップ5のSecrets登録まで済ませるのがおすすめ）
⚠️ トークンはチャットやメモに貼らないでください。コピーしたらそのままGitHub Secrets（ステップ5）に直接貼り付けます。

3Slackアプリからトークン2つ＋自分のIDを取る（アプリ作成済み✅）

📍 https://api.slack.com/apps → 作成したアプリを選択 → 左メニュー「OAuth & Permissions」

3-1. スコープの確認（トークンを取る前に）

「Scopes」の欄で次が付いているか確認。足りなければ追加してアプリを再インストール（Reinstall to Workspace）：

Bot Token Scopes（書き込み用）chat:write
User Token Scopes（徘徊読み取り用）channels:history groups:history im:history mpim:history channels:read groups:read users:read

3-2. トークンをコピー

  • Bot User OAuth Token（xoxb- で始まる）→ Secretsの SLACK_BOT_TOKEN_MAIN へ
  • User OAuth Token（xoxp- で始まる）→ Secretsの SLACK_USER_TOKEN_MAIN へ

3-3. 自分のメンバーID

Slackアプリ（普段使う画面）で自分のプロフィールを開く → 「…」（その他）→ 「メンバーIDをコピー」（U で始まるID）→ Secretsの SLACK_USER_ID_MAIN へ

4GoogleカレンダーのICS限定公開URLを取る

「限定公開URL」＝URLを知っている人だけが読める、カレンダーの読み取り専用アドレスです。OAuth不要で秘書がカレンダーを読めるようになります。

  1. Googleカレンダーの設定 を開く（個人アカウント nakashima.keitarou@gmail.com でログインした状態で）
  2. 左の「マイカレンダーの設定」から自分のメインカレンダー（自分の名前のもの）をクリック
  3. 下にスクロールして「カレンダーの統合」セクションへ
  4. 「限定公開URL（iCal形式）」の欄のURL（https://calendar.google.com/calendar/ical/…/private-…/basic.ics）をコピー → Secretsの GCAL_ICS_URL へ
⚠️ このURLは実質パスワードです（知っている人は予定を全部読めます）。Secrets以外に貼らないでください。もし漏れたら同じ画面の「リセット」ボタンで無効化できます。

5BRAIN_REPO_TOKEN（脳リポジトリ用トークン）を発行する

「脳リポジトリ」＝ persona・設定・状態を持つ非公開の別リポジトリ（slack-secretary-brain）です。実行用の本リポジトリ（public・無料）が、このトークンで脳リポジトリを読み書きします。

  1. https://github.com/settings/personal-access-tokens/new を開く（Fine-grained tokens）
  2. Repository access: 「Only select repositories」→ slack-secretary-brain だけを選択
  3. Permissions → 「Repository permissions」→ Contents を Read and write に設定
  4. 「Generate token」を押し、発行された github_pat_… をコピー → 次のステップの BRAIN_REPO_TOKEN へ
⚠️ Repository accessは必ずslack-secretary-brainのみに絞ってください（他のリポジトリへのアクセス権を持たせない）。

7動作確認（実機E2E）

  1. secretary workflow を開き「Run workflow」で手動実行 → 緑になることを確認
  2. Slackで、脳リポジトリ（slack-secretary-brain）の config/workspaces.json の replyAllowlist に入っているチャンネルで、自分宛てにメンションしてもらう（自分の別アカウント等でも可）
  3. 5〜15分以内に「けいたろう秘書」から注記つきのスレッド返信が来ればE2E成功 🎉

返信させるチャンネルを増やす・読み取り除外を設定するときは、脳リポジトリ（slack-secretary-brain・非公開）側の config/workspaces.json を編集します（COOに指示いただければこちらで対応します）。
